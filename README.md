# Blog da Jady

Projeto simples para praticar HTML, CSS e JavaScript.

## Como abrir

Abra o arquivo `index.html` em um navegador. Para criar uma postagem, preencha o
título e a descrição, escolha uma imagem se quiser e clique em **Publicar**.

Cada postagem tem seu próprio campo para escrever comentários.

## Para estudar

- `index.html` contém os campos e as áreas da página.
- `styles.css` muda as cores, os espaços e a aparência.
- `script.js` cria as postagens e os comentários.

As postagens e os comentários existem somente enquanto a página estiver aberta.
Ao atualizar ou fechar o navegador, eles desaparecem. Este projeto ainda não
usa banco de dados.
